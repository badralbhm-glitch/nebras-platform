## نظام الفروع وسير العمل
- main: النسخة المستقرة المعتمدة (يُمنع الدمج المباشر فيه)[cite: 8].
- develop: فرع التجميع والاختبار المشترك للفريق[cite: 8].
- الفروع الجانبية: تُنشأ من أحدث develop بأسماء واضحة مثل eature/... أو ix/...[cite: 8].
- لا يُدمج أي فرع في develop إلا عبر **Pull Request** وبعد مراجعة عضو آخر ونجاح الاختبارات[cite: 2, 8, 13].
- لا يتم رفع ملفات .env أو المفاتيح السرية إلى المستودع (يُستخدم .env.example فقط)[cite: 8].
